Contenido de la carpeta software
--------------------------------

- common/
  Ficheros base del framework proporcionado: mh.h, problem.h, random.hpp, etc.

- datos_portfolio_2526/
  Conjuntos de datos usados en los experimentos:
  ibex_35.csv, syp_100.csv y syp_500.csv.

- inc/
  Cabeceras de las clases implementadas:
  portfolio.h              - Definición del problema Portfolio.
  greedy.h                 - Algoritmo Greedy.
  randomsearch.h           - Algoritmo Aleatorio.
  localsearch.h            - Búsqueda Local (BL).
  memetic.h                - AM-Best, usado como mejor algoritmo de la P2.
  bmb.h                    - Búsqueda Multiarranque Básica.
  simulatedannealing.h     - Enfriamiento Simulado.
  ils.h                    - ILS con BL.
  ilses.h                  - ILS hibridado con ES.
  grasp.h                  - GRASP extra.
  portfolio_convergencia.h - Variante para registrar curvas de convergencia.

- src/
  Implementaciones de los algoritmos:
  portfolio.cpp            - Fitness, reparación y generación de soluciones.
  greedy.cpp               - Construcción voraz.
  localsearch.cpp          - BL primero-mejor con ratio=0.4.
  memetic.cpp              - Algoritmo memético usado como referencia de P2.
  bmb.cpp                  - BMB con varios arranques independientes.
  simulatedannealing.cpp   - Enfriamiento Simulado con Cauchy modificado.
  ils.cpp                  - ILS-BL.
  ilses.cpp                - ILS-ES.
  grasp.cpp                - GRASP extra: construcción semi-voraz + BL.

- resultados/
  Ficheros CSV generados por el programa principal y los scripts:
  resultados_medias.csv       - Medias de fitness, beneficio, evaluaciones y tiempo.
  semillas_utilizadas.csv     - Semillas empleadas en cada ejecución.
  configuracion_usada.txt     - Parámetros con los que se ejecutó el programa.
  boxplot_ibex_35.csv         - Datos de fitness por ejecución para boxplot.
  boxplot_syp_100.csv
  boxplot_syp_500.csv
  convergencia_ibex_35.csv    - Curvas de convergencia.
  convergencia_syp_100.csv
  convergencia_syp_500.csv
  sensibilidad_es_phi.csv     - Sensibilidad de ES respecto a phi.
  sensibilidad_es_mu.csv      - Sensibilidad de ES respecto a mu.
  wilcoxon.csv                - Resultados del test de Wilcoxon.

- graficas/
  Imágenes PNG generadas por los scripts Python:
  boxplots/                   - Boxplots principales de P3.
  convergencia/               - Curvas de convergencia.
  tiempos/                    - Comparativas de tiempos.
  sensibilidad_es/            - Sensibilidad de ES para phi y mu.
  comparacionGrasp/           - Comparación específica de GRASP frente a métodos similares.
  comparacionILS/             - Comparación de variantes extra de ILS e ILS-ES.
  wilcoxon/                   - Test de Wilcoxon.

- main.cpp
  Programa principal. Ejecuta Greedy, Random, BL, AM-Best, BMB, BMB-10,
  GRASP, ES, ILS-BL, ILS-10, ILS-30, ILS-ES, ILS-ES-10 e ILS-ES-30
  sobre los tres datasets. También genera los
  CSV de sensibilidad de ES y convergencia.

- scripts/
  boxplots.py        - Boxplots principales de P3.
  convergencia.py    - Curvas de convergencia.
  boxplot_grasp.py          - Comparación específica de GRASP con BL, BMB e ILS-BL.
  boxplot_ils.py            - Comparación de ILS-10, ILS-BL, ILS-30, ILS-ES-10, ILS-ES e ILS-ES-30.
  sensibilidad_es_phi.py    - Sensibilidad de ES respecto a phi.
  sensibilidad_es_mu.py     - Sensibilidad de ES respecto a mu.
  tiempos.py               - Comparativa de tiempos.
  wilcoxon.py              - Test estadístico de Wilcoxon.

- generar_graficas.sh
  Script bash que lanza los scripts Python de P3 en orden.

- config.txt
  Fichero de configuración opcional. Permite cambiar sin recompilar:
  lambda, número de ejecuciones, presupuestos, iteraciones, semilla y
  parámetros del ES.

- CMakeLists.txt
  Fichero de configuración para compilar el proyecto con CMake.


Compilación
-----------

Opción 1 - Compilación directa:

  g++ -std=c++17 -O3 main.cpp src/*.cpp -Iinc -Icommon -o main

Opción 2 - Con CMake:

  mkdir -p build
  cd build
  cmake ..
  make


Ejecución
---------

Ejecutar siempre desde la carpeta software, ya que las rutas son relativas:

  ./main
  ./main config.txt

Con CMake, ejecutando también desde la carpeta software:

  ./build/main
  ./build/main config.txt


Generación de gráficas
----------------------

Tras ejecutar el programa principal, generar todas las gráficas con:

  bash generar_graficas.sh

O ejecutar cada script por separado:

  python3 scripts/boxplots.py
  python3 scripts/convergencia.py
  python3 scripts/boxplot_grasp.py
  python3 scripts/boxplot_ils.py
  python3 scripts/sensibilidad_es_phi.py
  python3 scripts/sensibilidad_es_mu.py
  python3 scripts/tiempos.py
  python3 scripts/wilcoxon.py

Las imágenes se guardan en graficas/.
